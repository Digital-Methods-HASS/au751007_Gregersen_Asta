Doing some wrangling:

Firstly, we’re splitting pages up into separate lines (separated by \n) using stringr::str_split() Then, unnesting into regular columns using tidyr::unnest() Lastly, removing leading and trailing white space stringr::str_trim()

got_df <- data.frame(got_text) %>% 
  mutate(text_full = str_split(got_text, pattern = '\n')) %>% 
  unnest(text_full) %>% 
  mutate(text_full = str_trim(text_full))

Now each line, on each page, is its own row, with extra starting & trailing spaces removed.

Getting the individual words in a tidy format

Using tidytext::unnest_tokens() to split columns into tokens. In this analysis, the words are vital, so we’ll use the token ‘word’.

got_tokens <- got_df %>%

# One word that can be argued is not primarily positive, is 'slick'. If a person is described slick, one is likely to have a sly and conniving nature. Thus, it can be negative. Another usage of the word is to describe the state of something one is feeling and sensing to be slick, such as a muddy road, or a person feeling slick with sweat. A muddy road or sweat is not overtly negative, but calling it positive also seem s strange. However, something can also be described as slick, if it is smooth, plain or glossy, such as the surface of a forest lake, it is not negative.

Looking at the book, slick is at one time used to describe an object, an arrowhead, which is mentioned as “The black glass was slick and shiny. [Bran] thought it beautiful”, on page 670 in the PDF. This is clearly positive, as the person observing the arrowhead believes it to be beautiful. However, quite a lot of instances of slick is used to describe someone or something being slick with blood. Such is the instance on page 127 “The dagger was still clutched tightly in his right hand, slick with blood”. This is quite negative, as one is holding a dagger, slick with another person’s blood.

This goes to show that a sentiment lexicon matching words will not distinguish between different uses of the words. This does not mean it is not useful, but one should rely solely on its output in one’s analysis.

However, it does tell us something about the words used. When summarizing and finding the median and the average value, one finds the average to be -0,541 and the median to be -1. Based on this, one can conclude that according to the afinn lexicon, Game of Thrones has more negative words than it has positive. As I expected, the book has more negtaive values then positive, However, not as negative as I believed it be before I started this sentiment analysis.

Conclusion

Sentiment analysis is quite a useful tool to gain a quick and concise overview of the sentiments within a text. Doing this analysis, I learned that in the book Game of Thrones, negative emotions do not dominate nearly as much as I believed they would. In this particular case, it showcases that the book might not be as dark as people believe it to be. Perhaps this might inspire people, who previously believed the novel to be far too dark and negative for them, to give the book a proper chance. Using sentiment analysis on historical texts can also be useful. One might view a particular period in history as being predominately very dark and negative, or very positive and light. However, using sentiment analysis on texts of the time, one might be able to shine a light on new aspects of a certain historical period. Sentiment analysis makes this reexamination quick and easy. If one discovers nuances not previously known, then one can begin to do close-reading of the texts, to examine and highlight the new found aspects of the time.
